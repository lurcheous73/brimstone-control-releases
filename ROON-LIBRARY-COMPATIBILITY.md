# Tested: playback from Roon-managed music libraries

**Brimstone Core R1 · Interoperability note · 8 November 2026**

Brimstone Core is an **independent music server and player**. In development testing, it has successfully **played music from a library managed by Roon**. This is the practical interoperability result we're sharing.

![Brimstone Core R1 album library](https://core-audio.uk/assets/showcase/core-albums.jpg)

## What “Roon-compatible” means here

| Capability | Evidence / scope |
| --- | --- |
| Music originating in a Roon-managed library can be played through Brimstone Core | **Reported tested and working** in the development setup |
| Brimstone is a Roon Server replacement with identical functions | **Not claimed** |
| Brimstone is an officially certified Roon Ready endpoint | **Not claimed** |
| Universal RAAT/RAAT endpoint, Roon Bridge, or Roon API compatibility | **Not established by this library-playback test** |
| Automatic bidirectional catalogue, favourites, edits or queue synchronisation | **Not established by this library-playback test** |

The library-playback result should not be confused with **Roon Ready**, **Roon Tested**, or any official certification. Those are distinct vendor programmes.
