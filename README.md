# Brimstone Control Releases

Public binary releases for **Brimstone Control**.

The application source remains in the private Brimstone development repositories. This repository contains release notes, checksums and downloadable builds only.

## Windows Open Beta

Use the **Installer** for a normal Windows installation, or the **Portable** build for testing without installation.

The APPX file attached to releases is the Microsoft Store submission package and is not intended for normal direct sideload installation.

Project website: https://core-audio.uk
