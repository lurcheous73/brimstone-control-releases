### An independent music server, Roon-compatible library playback, and a modern music player for the hardware you love.

**Brimstone Core** is an independent, self-hosted music server and audiophile playback platform designed for local music collections, classic audio hardware, and modern listening interfaces. It is built around Debian, with dedicated Control clients and a growing set of audio transports.

## Roon-compatible library playback — tested 🎶

**Brimstone Core has now been tested playing music from Roon-managed libraries.** That's a practical interoperability milestone for listeners who already have a Roon music collection and want to explore Brimstone alongside their existing setup.

- **Tested:** playback of music from a Roon-managed library through Brimstone Core.
- **Separate product:** Brimstone is not Roon Server, Roon Core, or Roon Bridge.
- **No certification claim:** this does **not** mean Brimstone is officially *Roon Ready*, Roon Tested, or certified by Roon Labs.
- For the implementation context and changing test coverage, see [Roon library compatibility](ROON-LIBRARY-COMPATIBILITY.md).

If you're searching for **Roon music server software**, **Roon library playback**, **Roon alternatives**, or **self-hosted music players**, [see Brimstone's Roon music server guide](https://core-audio.uk/roon-music-server.html).

**Music and streaming discovery:** Spotify, Apple Music, TIDAL, Qobuz, Bandcamp Radio, internet radio, Audius and Jamendo are among the streaming services and catalogues Brimstone works with or is developing integrations for. Availability depends on the service and current release.

**Audio hardware and protocols:** Meridian / Sooloos / MS200, Sonos, Lyrion Music Server / Squeezebox, Google Cast / Chromecast, AirPlay, UPnP / DLNA and Roon library interoperability feature in Brimstone's testing and transport roadmap.

**CarPlay:** Brimstone Control has working CarPlay support, connecting securely to your home Core. [Explore CarPlay](https://core-audio.uk/carplay.html).

## Core, Control & Store

- **Core** — the self-hosted Debian music server, catalogue and playback coordinator.
- **Control** — companion experiences for browsing, playing and managing music across supported devices.
- **Store** — a separate Debian-based system for library storage and associated services.

**Latest public download links and SHA-256 checksums:** [BRIMSTONE-DOWNLOADS.md](BRIMSTONE-DOWNLOADS.md) · [Installation guide](https://core-audio.uk/install.html) · [Release notes](https://core-audio.uk/releases.html)

> Brimstone Core R1 is in active testing. Compatibility varies by device, transport and provider. Roon interoperability described above refers to the tested Roon-managed library playback path, not a blanket promise of RAAT endpoint certification or complete feature parity.
