The multi-gigabyte ISO images are hosted on the product download server. GitHub Release assets are limited to files under 2 GiB, so do not treat this repository as a complete mirror of the ISO binaries.

## Earlier builds

Superseded RC2, RC6 and RC13 packages have been withdrawn from the main public downloads. Their original files and checksum records have been preserved in a private, recoverable binary archive pending packaging for public release storage. They are **not yet uploaded as GitHub assets**. Historical Windows Control assets are available on [this repository's Releases page](https://github.com/lurcheous73/brimstone-control-releases/releases).

Avoid installing historic Core builds unless you are performing a specific compatibility test.
